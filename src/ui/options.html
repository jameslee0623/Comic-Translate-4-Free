    Automation

    Images smaller than this are skipped.

    When on, allowed pages start translating automatically as soon as they finish loading — no button click needed. (Tip: allow a site from the popup so the extension gets permission to read its images.)

    While you read this page, the next page is translated in the background, so it is ready when you open it.

    Models

    Models are downloaded from Hugging Face once and cached in the browser (IndexedDB).

    Translated page cache

    Pages you revisit in this browser session load instantly from a temporary cache. The cache is cleared automatically when the browser closes.

    Azure is being retired

    Use Gemini for better translations. Azure will be removed in a future version.

    1. Open Google AI Studio and create an API key — free, no credit card needed. aistudio.google.com/apikey
    2. Copy the key.
    3. Paste it into the Gemini API key field in Settings, then click Check Gemini connection.
    4. Pick Gemini as the translating engine.
